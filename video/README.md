# AgentGraph demo video

Source for the ~60s walkthrough at [`../docs/demo-video.mp4`](../docs/demo-video.mp4) — see the main [README](../README.md#demo) for context. Composed in `src/MyVideo.tsx` from scenes in `src/scenes/`, using real screenshots of the deployed app (`public/screens/`) and an original synthesized background pad (`public/audio/bgm.m4a`, generated by `scripts/generate_bgm.py` — plain sine-wave synthesis, no third-party audio, so no licensing question). Regenerate the video with `npm i && npx remotion render AgentGraphDemo out/agentgraph-demo.mp4`; regenerate the audio (needs Python + numpy) with `python3 scripts/generate_bgm.py && ffmpeg -y -i public/audio/bgm.wav -c:a aac -b:a 128k public/audio/bgm.m4a`.

## Commands

**Install Dependencies**

```console
npm i
```

**Start Preview**

```console
npm run dev
```

**Render video**

```console
npx remotion render
```

**Upgrade Remotion**

```console
npx remotion upgrade
```
